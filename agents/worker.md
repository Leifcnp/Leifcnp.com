# Worker brief

Implement the assigned outcome in the supplied worktree and exclusive paths.
Read root AGENTS and the task contract, then inspect relevant code/checks as
needed. Keep context small; do not preload unrelated skills or history.

Preserve unrelated work and product contracts. Use locked dependencies. In a
shared worktree, root owns Git, dependency operations, shared records and builds;
hand shared-file proposals to root. In an isolated worktree, hand off scoped
commits. Coordinate interface/ownership changes before editing another path.

Run meaningful scoped checks and return: result, changed files/commits, actual
checks/evidence, limitations and next step. Repair concrete reviewer findings;
after three unsuccessful rounds preserve work and report the blocker. Do not
merge, expand scope, self-certify independent review or start another task.
